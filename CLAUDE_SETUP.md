# Claude GitHub App Setup Guide

## Overview
This guide helps you set up the Claude GitHub App to automatically review PRs and respond to code review requests in your repository.

## Current Status ✅
- ✅ Claude GitHub App Installed
- ✅ GitHub Actions Workflow Created (`.github/workflows/claude-review.yml`)
- ⏳ Requires API Configuration for Full Functionality

## Why Claude Bot Isn't Responding Yet

The workflow runs successfully, but the bot doesn't post comments because:
1. The workflow needs **ANTHROPIC_API_KEY** secret configured
2. The workflow needs logic to post actual review comments to GitHub
3. The GitHub App needs proper webhook configuration

## Solution: Step-by-Step Setup

### Step 1: Get Anthropic API Key
1. Go to https://console.anthropic.com/account/keys
2. Create a new API key
3. Copy the key (you'll need it in the next step)

### Step 2: Add API Key as GitHub Secret
1. Go to your repository: https://github.com/harshp-fabninjas/laravel-scheduler
2. Click **Settings** → **Secrets and variables** → **Actions**
3. Click **New repository secret**
4. Name: `ANTHROPIC_API_KEY`
5. Value: Paste your Anthropic API key
6. Click **Add secret**

### Step 3: Alternative - Use Enhanced Workflow with Python

Replace the contents of `.github/workflows/claude-review.yml` with the code below:

```yaml
name: Claude AI Code Review

on:
  pull_request:
      types: [opened, synchronize, reopened]

      jobs:
        claude-review:
            runs-on: ubuntu-latest
                permissions:
                      pull-requests: write
                            contents: read

                                steps:
                                      - uses: actions/checkout@v4
                                              with:
                                                        fetch-depth: 0

                                                              - uses: actions/setup-python@v4
                                                                      with:
                                                                                python-version: '3.11'

                                                                                      - name: Install dependencies
                                                                                              run: pip install anthropic requests

                                                                                                    - name: Claude Code Review
                                                                                                            env:
                                                                                                                      GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
                                                                                                                                ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
                                                                                                                                          PR_NUMBER: ${{ github.event.pull_request.number }}
                                                                                                                                                  run: |
                                                                                                                                                            python - << 'EOF'
                                                                                                                                                                      import os
                                                                                                                                                                                import json
                                                                                                                                                                                          import requests
                                                                                                                                                                                                    from anthropic import Anthropic
                                                                                                                                                                                                    
                                                                                                                                                                                                              # Initialize
                                                                                                                                                                                                                        gh_token = os.environ['GITHUB_TOKEN']
                                                                                                                                                                                                                                  pr_num = os.environ['PR_NUMBER']
                                                                                                                                                                                                                                            repo = '${{ github.repository }}'
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                      # Get PR files
                                                                                                                                                                                                                                                                headers = {'Authorization': f'token {gh_token}'}
                                                                                                                                                                                                                                                                          url = f'https://api.github.com/repos/{repo}/pulls/{pr_num}/files'
                                                                                                                                                                                                                                                                                    files = requests.get(url, headers=headers).json()
                                                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                              # Prepare code summary
                                                                                                                                                                                                                                                                                                        code_text = "Files changed:\n"
                                                                                                                                                                                                                                                                                                                  for f in files[:5]:
                                                                                                                                                                                                                                                                                                                                code_text += f"\n{f['filename']}\n"
                                                                                                                                                                                                                                                                                                                                              if f.get('patch'):
                                                                                                                                                                                                                                                                                                                                                                code_text += f.get('patch')[:300] + "...\n"
                                                                                                                                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                                                                                                          # Get Claude review
                                                                                                                                                                                                                                                                                                                                                                                    client = Anthropic()
                                                                                                                                                                                                                                                                                                                                                                                              msg = client.messages.create(
                                                                                                                                                                                                                                                                                                                                                                                                            model="claude-3-5-sonnet-20241022",
                                                                                                                                                                                                                                                                                                                                                                                                                          max_tokens=500,
                                                                                                                                                                                                                                                                                                                                                                                                                                        messages=[{"role": "user", "content": f"Review this code:\n{code_text}"}]
                                                                                                                                                                                                                                                                                                                                                                                                                                                  )
                                                                                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                                                                                            review = msg.content[0].text
                                                                                                                                                                                                                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                                                                                                                                                                                                                      # Post to GitHub
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                comment = {'body': f'## 🤖 Claude Review\n\n{review}'}
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          url = f'https://api.github.com/repos/{repo}/issues/{pr_num}/comments'
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    requests.post(url, json=comment, headers=headers)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              print("✅ Review posted!")
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        EOF
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        ```
